# Situação 3 – Testes com usuários (colegas)

Testes com usuários (colegas) – será preenchido na Situação 3.

Ainda não fiz nenhum teste com colegas. Esta pasta fica reservada para os relatórios
que vou receber de quem testar o sistema.

## Campos de cada relatório de teste

Para cada pessoa que testar o sistema, vou registrar:

1. **Nome de quem testou**
2. **Data do teste**
3. **O que testou e funcionou**
4. **O que testou e não funcionou** (e o que deve ser corrigido)
5. **Funcionalidade não testada** (e por quê)
