# Protótipo revisado – Situação 1

Protótipo de média fidelidade do App de Cupcakes Gourmet, feito a partir do Plano de Melhoria do
Protótipo (seção 11 do relatório `Situacao1_Revisao_Planejamento.docx`). Não é código e ainda não foi
avaliado por colegas nem testado com usuários.

| Arquivo / pasta | Conteúdo |
|---|---|
| `prototipo_situacao1.pdf` | 18 páginas (A4 paisagem): telas agrupadas por fluxo, interações, rastreabilidade, comparação com o PI I, estados de erro e verificação de consistência |
| `mapa_navegacional_situacao1.png` | Mapa navegacional montado com as telas |
| `telas/` | 33 imagens PNG: 19 telas (T01–T15, A01–A04) + 14 estados (arquivos com letra: T03b, T03c...) |
| `fonte-svg/` | As mesmas 33 telas em SVG editável (Inkscape ou importação no Figma) |
| `pi1_wireframes_originais.png` | Wireframes originais do PI I, para comparação |

Códigos das telas e mensagens seguem as seções 10.2 e 10.4 do relatório.
